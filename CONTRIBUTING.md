# Contributing

Contributions to the public TypeScript client and stdio server are welcome.

1. Use Node.js 20 or newer.
2. Run `npm ci`.
3. Keep changes within the public package, tests, documentation, manifests, and owned brand assets.
4. Add or update tests beside the source.
5. Run `npm run validate` before proposing a change.

Do not commit secrets, environment files, generated `dist`, `node_modules`, account data, production identifiers, third-party logos, or proprietary backend code. By contributing, you agree that your contribution is licensed under MIT.
