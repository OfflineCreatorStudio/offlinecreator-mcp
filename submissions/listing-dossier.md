## Listing copy

**Tagline:** Create images and videos with OfflineCreator Studio.

OfflineCreator Studio connects MCP clients to cloud image and video generation workflows. Users can inspect available models and credit costs, start generations, attach source images for supported workflows, monitor progress, and retrieve short-lived output links. Remote connections use OAuth discovery; local stdio uses a personal API key.

## Distribution truth
