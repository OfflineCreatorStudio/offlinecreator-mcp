# Support

Start with [installation](docs/install.md) and [client notes](docs/clients.md).

For product or account help, use [OfflineCreator Studio support](https://offlinecreatorstudio.com/contact). For reproducible package bugs, use the repository issue tracker after removing credentials and private media. Security reports must follow [SECURITY.md](SECURITY.md).

Include the package version, Node.js version, MCP client and version, transport (remote or stdio), sanitized error text, and minimal reproduction steps.
